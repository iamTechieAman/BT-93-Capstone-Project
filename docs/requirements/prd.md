# Product Requirements Document (PRD): Smart GST System

## 1. Objective
To streamline GST compliance for Indian businesses by providing an automated AI tool that classifies products, validates rates against official Notifications, and generates GST-validated invoices.

## 2. Key Features
- **Instant Product Verification**: Accepts natural language descriptions (e.g. "Leather Jacket with Zip").
- **Audit-Ready Evidence**: Displays why a specific HSN code was selected alongside legal evidence badges.
- **B2B GST Invoice Module**: Generates PDF tax invoices with automated CGST/SGST/IGST calculation.
- **Knowledge Graph Visualizer**: Renders product-material-tax relationships in real time.
