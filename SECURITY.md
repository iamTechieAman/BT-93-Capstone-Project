# Security Policy

## Supported Versions

Security updates and critical bug fixes are applied to the active branch:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this repository, please do not disclose it publicly or file a public GitHub issue.

Instead, please report security vulnerabilities directly:
- **Email**: `er.amankumar@hotmail.com`
- **Subject**: `[SECURITY VULNERABILITY] Smart GST System`

Please include the following information in your report:
1. Type of issue (e.g., SQL injection, authentication bypass, CSRF, remote code execution)
2. Affected components and file paths
3. Step-by-step instructions or proof-of-concept to reproduce the vulnerability
4. Any potential mitigations or workarounds you have identified

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours
- **Assessment & Triage**: Within 5 business days
- **Remediation & Patch**: Target release within 14 calendar days depending on severity

Responsible disclosure and coordinated release practices are strictly followed.
